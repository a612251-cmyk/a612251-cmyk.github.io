如何設定 Azure 應用程式（點擊展開）
  1. 前往 Azure Portal → 應用程式註冊
  2. 點擊「新增註冊」
  3. 名稱：任意（如「工作提醒板」），帳戶類型選「個人 Microsoft 帳戶」
  4. 重新導向 URI：類型選「單頁應用程式 (SPA)」，URI 填入下方網址
  5. 完成後複製「應用程式 (用戶端) 識別碼」貼至下方
